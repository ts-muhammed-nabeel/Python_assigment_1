# Python Fundamentals: Strings & Tuples

## 📌 Project Overview

This project demonstrates the fundamentals of Python programming, focusing on **string manipulation and tuple operations**. It includes practical examples of string concatenation, indexing, slicing, built-in string methods, and tuple manipulation.

The project was created as part of a Python fundamentals assignment to develop a basic understanding of Python data structures and operations.

## 🎯 Objectives

- Understand string concatenation and manipulation.
- Perform string indexing and slicing.
- Use built-in string methods.
- Combine and repeat tuples.
- Access individual tuple elements and extract slices.
- Develop basic Python programming skills through practical exercises.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Environment:** Jupyter Notebook
- **File Format:** `.ipynb`

## 📚 Topics Covered

### 1. String Operations

- String concatenation using the `+` operator.
- Taking user input with `input()`.
- Accessing the first and last characters using indexing.
- Extracting substrings using slicing.
- Reversing strings using slicing.
- Converting strings to uppercase and lowercase.
- Capitalizing strings.
- Counting character occurrences.
- Replacing words within a string.

### 2. Tuple Operations

- Creating tuples.
- Combining tuples using the `+` operator.
- Repeating tuples using the `*` operator.
- Accessing tuple elements using indexing.
- Extracting elements using tuple slicing.
